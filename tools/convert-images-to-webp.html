Word Slice image optimizer

Converts the fruit sprites and the question-card artwork from PNG to WebP using the browser's own canvas encoder (no external dependencies). This reproduces the one-time optimization described in tools/OPTIMIZATION.md.

  1. Run node tools/prep-fruits.mjs to regenerate the PNG sprites from the original downloads (writes assets/fruits/sprites/<group>/<fruit>.png).
  2. Serve the project (npm start) and open this file via the server URL: http://localhost:3000/tools/convert-images-to-webp.html.
  3. Click the button. Every converted file downloads as <name>.webp into your download folder.
  4. Move the downloaded .webp files over the matching paths in assets/fruits/sprites/ and assets/ui/, then delete the superseded .png files.
